Gestión de Bases de Datos Avanzada

Diseña esquemas optimizados, trabaja con bases relacionales y NoSQL, y domina consultas avanzadas y operaciones de manipulación sobre grandes volúmenes de datos.

Comenzar teoría Ir a la práctica

¿Qué aprenderás en este tema?

La gestión de datos a escala requiere más que saber escribir un SELECT. En este tema profundizarás en el diseño de esquemas, la normalización, la optimización, el uso de PostgreSQL/MySQL y MongoDB, y el acceso a bases de datos desde Python (SQLAlchemy, psycopg2, pymongo).

Competencias específicas a desarrollar

  • Diseñar esquemas de bases de datos avanzadas para almacenar y gestionar grandes volúmenes de datos.
  • Realizar consultas avanzadas y operaciones de manipulación en bases relacionales y NoSQL.
  • Dominar herramientas de gestión (SQL, sistemas de gestión de bases de datos específicos).
  • Integrar la gestión de bases de datos en el proceso de análisis de datos, desde la adquisición hasta la presentación de resultados.
  • Considerar requisitos de privacidad y seguridad en el diseño y la gestión de datos.

Herramientas que usarás

Herramienta Rol
PostgreSQL / MySQL / SQLite Bases de datos relacionales
MongoDB Base de datos NoSQL documental
SQLAlchemy / psycopg2 / sqlite3 Acceso desde Python
pymongo Cliente oficial de MongoDB para Python
pandas Lectura/escritura de resultados de consultas
💡 Consejo Para la práctica local puedes usar SQLite (no requiere servidor). Para un entorno más realista, instala PostgreSQL o usa un contenedor Docker.

Estructura recomendada de estudio

  1. Teoría 4.1: Diseño, normalización e índices.
  2. Teoría 4.2: Comparar relacional vs NoSQL y practicar conexiones.
  3. Teoría 4.3: Consultas avanzadas y transacciones.
  4. Práctica Jupyter: Implementar el esquema, cargar datos y consultar.
  5. Proyecto: Base de datos para un caso de analítica (ventas, sensores, clientes).
