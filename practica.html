💻 Práctica: Gestión de Bases de Datos Avanzada

Diseñarás un esquema, crearás la base con SQLite, cargarás datos, ejecutarás consultas avanzadas y practicarás CRUD. Opcionalmente trabajarás con MongoDB.

📦 Archivos de la práctica

⬇️ practica_tema4.ipynb ⬇️ schema_tienda.sql ⬇️ datos CSV

Notebook: notebooks/practica_tema4.ipynb
Esquema SQL: sql/schema_tienda.sql
Datos: data/*.csv

Objetivos

  • Crear un esquema normalizado (tienda: clientes, productos, pedidos, detalle).
  • Cargar datos y verificar integridad referencial.
  • Escribir JOINs, agregaciones, CTEs y window functions.
  • Implementar transacciones y operaciones CRUD seguras.
  • (Opcional) Replicar un subconjunto del modelo en MongoDB.

Estructura del notebook

Sección Contenido Tiempo
0. Configuración sqlite3, pandas, rutas 5 min
1. Esquema CREATE TABLE, PK, FK, índices 25 min
2. Carga de datos CSV → tablas, validación 20 min
3. Consultas avanzadas JOINs, CTE, ventanas, HAVING 40 min
4. Transacciones y CRUD Pedido con descuento de stock 25 min
5. Caso práctico Informe de ventas con SQL 35 min
6. Retos MongoDB opcional, optimización 30+ min

Cómo ejecutar

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
jupyter lab
# Abrir notebooks/practica_tema4.ipynb
📌 Evaluación Se valorará: corrección del esquema, calidad de las consultas, uso de transacciones, parametrización (seguridad) y claridad de la documentación.
